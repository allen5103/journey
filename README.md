# 一趟旅程｜離線版

這個儲存庫發布「一趟旅程」的單一 HTML 離線版本。公開網站位於：<https://allen5103.github.io/journey>。

## 使用方式

直接以瀏覽器開啟網站即可建立旅程、安排每日行程、附加照片、使用日期與時間欄位、查看時間空檔，以及匯出或匯入旅程備份。此版本不包含 Google Maps、地點搜尋或內嵌地圖。

## 資料與備份

資料會儲存在**目前瀏覽器、目前網站來源**的 Local Storage；清除該網站的瀏覽資料、改用不同瀏覽器或不同裝置，都不會自動帶入既有資料。請定期使用頁面內的 JSON 匯出功能備份旅程。

照片會以資料網址嵌入瀏覽器儲存空間。大量或高解析照片可能讓瀏覽器可用空間較快耗盡，建議使用適量且經壓縮的圖片。

## 本機離線使用

若要在沒有網路時使用，可下載此儲存庫的 `index.html` 後，直接從裝置檔案系統開啟。離線檔和公開網站使用不同的資料儲存範圍，請透過 JSON 匯出／匯入在兩者之間移轉資料。

## 發布內容

- `index.html`：完整單一檔案應用程式，內嵌樣式與互動程式。
- `.nojekyll`：避免 GitHub Pages 以 Jekyll 處理靜態檔案。
